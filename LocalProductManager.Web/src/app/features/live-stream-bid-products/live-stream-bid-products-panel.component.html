Safe start calculation

1. Product cost in USDTotal Cost (RMB) × current RMB→USD rate

2. Protected operating costProduct cost × 1.10 + $0.25 packaging + ($25 ÷ 60) host labor

3. Fixed and ancillary fees$0.30 processing + ($10 assumed shipping/tax × 2.9%)

4. Platform retained-sale rate1 − 8% commission − 2.9% processing − 1% fee-tax reserve = 88.1%

5. Safe starting priceCeiling((protected cost + fixed/ancillary fees) ÷ 88.1%)

Host labor allowance$25 per hour ÷ 60 packages per hour = $0.4167 per sold package. It is included before platform fees are reversed.

The result is rounded up to the next whole dollar. It is a break-even safety estimate, not a guaranteed profit or final selling price.
