LAN INTEGRATION

Build an eBay listing from another computer

Use the website/API host shown above. Do not connect the other computer directly to PostgreSQL.

  1. Find the productExact lookup accepts either an Inventory ID such as INV-66 or the product SKU.
    GET {{ apiBaseUrl }}/products/lookup?code=INV-66
  2. Read the main product recordUse the returned id to obtain name, SKU, cost, quantity, weight, dimensions, category, listings, and ASIN data.
    GET {{ apiBaseUrl }}/products/{productId}
  3. Read eBay-supporting fieldsThis includes material, specification, description, country of origin, HS code, safety flags, packaging, identifiers, supplier data, and stored prices.
    GET {{ apiBaseUrl }}/products/{productId}/extended-data
  4. Download product mediaDownload photos only or all photos/videos as ZIP, or list and request individual encoded file names.
    GET {{ apiBaseUrl }}/products/{productId}/image/files/download-all
GET {{ apiBaseUrl }}/products/{productId}/image/files/download-all-media
GET {{ apiBaseUrl }}/products/{productId}/image/files
GET {{ apiBaseUrl }}/products/{productId}/image/files/{encodedFileName}
GET {{ apiBaseUrl }}/products/{productId}/image?thumbnail=512

PowerShell

$base = "{{ apiBaseUrl }}"
$product = Invoke-RestMethod "$base/products/lookup?code=INV-66"
$detail = Invoke-RestMethod "$base/products/$($product.id)"
$extra = Invoke-RestMethod "$base/products/$($product.id)/extended-data"
$images = Invoke-RestMethod "$base/products/$($product.id)/image/files"

C# HttpClient

var baseUrl = "{{ apiBaseUrl }}";
var product = await http.GetFromJsonAsync<Product>(
    $"{baseUrl}/products/lookup?code={Uri.EscapeDataString("INV-66")}");
var detail = await http.GetFromJsonAsync<ProductDetail>(
    $"{baseUrl}/products/{product!.Id}");
var extra = await http.GetFromJsonAsync<ProductExtendedData>(
    $"{baseUrl}/products/{product.Id}/extended-data");
Access: Product and image GET endpoints are read-only and work as a guest on the LAN. For protected write endpoints, call POST {{ apiBaseUrl }}/auth/login, keep the returned lpm_session cookie, and send it on later requests.

Permission model

Admin-only actions include imports, storage root changes, social account connect/disconnect, manual metrics, attribution edits, user management, and AI report execution. Guest and regular users can browse allowed product, file, marketing, and analytics data without modifying protected records.
